## Implemented boundary

`Services/NetworkEnvironment.cs` defines disjoint typed selections:

- `Lan` has `LanRole.Join` or `LanRole.Host` and no Public transport.
- `Public` has `PublicTransport.Fast` or `PublicTransport.Compatible` and no LAN role.
- Invalid enum values are rejected; these concepts cannot be silently interchanged.
- The snapshot contains selection, readiness, switching/closed/activity flags,
  a bounded status enum and optional measured latency. It contains no endpoint,
  account, credential, token, raw exception string or adapter/process reference.

`NetworkEnvironmentController` serializes changes, checks active-game and owned
launch state before starting and before committing an asynchronous result, and
stops only its current owned connection lease before starting a different one.
Failure reconnects the previous selection and reports both the attempted-change
outcome and rollback result. Failed rollback remains explicitly not-ready. A
missing/unavailable Public adapter leaves the previous runtime intact and reports
unavailable; it never starts a hidden LAN fallback.

Caller cancellation rejects late candidate readiness and restores the prior
runtime using the controller lifetime token. Closing marks state closed before
awaiting cleanup and cancels that lifetime; a late target or rollback completion
is disposed instead of published. Failed owned disposal prevents another listener
from starting, is retained for retry, and failed close cleanup returns a fixed
error rather than claiming cleanup succeeded. No global process enumeration or
shutdown API is present.

Snapshots sample live owned-lease readiness and latency; disconnection becomes
explicitly not-ready, and a same-selection request reconnects a disconnected lease
instead of returning unchanged. Adapters must honor cancellation and provide
thread-safe, nonblocking, side-effect-free readiness/latency properties,
and own only resources they create. The activity accessor must be thread-safe;
future integration must not read WPF controls from background continuations.
An adapter that ignores cancellation can delay the completion of close until its
connection attempt returns; the tests verify that such a late result cannot
restore readiness or escape owned cleanup. This layer has no persistence or
production networking implementation.
