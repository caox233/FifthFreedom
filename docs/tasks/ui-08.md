# UI08 — Native API source constraint and revocation

Status: needs-triage. Implementation and local type checking are complete;
actual Windows socket execution and real owned overlay admission remain separate
gates. Ordinary Public admission remains closed.

The retained native API used tonic's default connector. Its cache generation
retired pending creators, but dropping a cached `Channel` did not close the
transport held by other clones. The retained game Winsock hooks attempted a
source bind and continued after bind failure; they did not check interface LUID
or constrain `IP_UNICAST_IF`. This change does not change those LAN game hooks or
claim confinement of game UDP.

`SocketBinding` records an immutable IPv4 source, interface index and LUID, and
one numeric destination. It is a socket constraint, not evidence of encryption,
peer readiness or an owned adapter session. The production `LiveOverlayLease`
factory always fails. Its only issuer is compiled inside tests. Presence of the
existing nonsecret Public-return descriptor selects the closed Public policy
once per process; it cannot create a lease, and later environment changes cannot
switch the policy. Normal LAN retains its original tonic connector and errors.

For an admitted lease, every initial connection and tonic reconnect checks the
exact live index/LUID/source via `GetIfEntry2` and
`GetUnicastIpAddressEntry`, requires interface up and a preferred valid address,
sets and reads back `IP_UNICAST_IF` in network byte order, binds source port zero,
and validates the connected local and remote endpoints. Destination DNS,
different authorities and wildcard fallbacks are rejected. Each connecting socket
is canceled with its lease, and completion is checked again before atomically
registering the stream. Connection time is bounded to one second.

The shared lease epoch serializes registration and synchronous publication with
revocation. Revocation first becomes sticky, cancels pending connection work,
takes and drops every registered socket, wakes read/write waiters, then clears
the API credential, observer admission, cached channel and Public-return state.
Existing tonic clones therefore cannot retain a working socket after revocation.
Interceptors, cache publication and successful login/return publication check the
same lease. No pipe I/O or await runs under the authority or stream-cell lock.
Only bounded state publication runs under the authority lock. The stream registry
is pruned and capped at 16 live connections.

Public owner loss is terminal for the loaded DLL: a process-wide sticky latch
and the permanently closed return bridge require a new owned launch. The
production issuer must not replace an old epoch in this process. Tests may create
independent synthetic epochs to check isolation; that test constructor is absent
from production. Supporting in-process replacement would first require matching
credential/cache cleanup to each epoch and a separately reviewed return lifecycle.

This slice supplies the connection consumer. It does not supply the production
owner/liveness monitor. A future issuer must revoke on owner exit, interface or
address loss, lease epoch change and secure-peer loss, and establish its Windows
kernel-session relationship before issuing anything. The pinned EasyTier source
uses `tun-easytier` commit
`12378839e7985283df0e4fb536b7137230356db5`: Windows creation first calls
`Adapter::open(name)` and only then `Adapter::create`. An adapter name, existing
LUID, historical LAN transport observation, return-pipe heartbeat, or configured
IP does not establish that relationship. Its firewall and registry mutation paths
also require a separate ownership review before runtime use. No driver, overlay,
game or external endpoint was started for this task.
