## 本轮集中测试

1. 主屏直接选择 MOD/官方、调整 FOV。修改和“默认”先进入草稿；取消或 Escape 不保存，保存后重启应保留。只有 DX11、一个设置入口；已通过的 F3、MAC11 HUD、中文/世界相机和 VSS EMF 范围无需整套重测。
2. 本轮联机选择“本地模式”。发现一个房主时确认预填信息，多个时自行选择；未响应可重扫、手填或确认创建。取消、切回公网和关闭窗口不得迟到弹窗或自动开服。默认公网可配置但必须明确显示未就绪，不能假充 LAN 连接成功。
3. 房主和至少两个客户端集中检查摄影机投出、接收、重复部署和销毁，记录是否仍同期退出；原单击/长按/双击行为保留。源码防护与合成回放没有证明原始零地址闪退已解决，另一例写入异常继续分开记录。
4. 同服、同模式、不同账号，使用现有角色对照 55/56/57/更高等级及混队/单人；不要改等级或存档造样本。快速匹配需在空大厅和已有房间都进入同一局，单客户端成功不算通过。三人全体/队伍聊天仍按随包说明验证。仅记通过/失败及卡住阶段即可，不要求上传私人日志。

电磁镜性能尚无同条件逐帧样本，不能报告 p95/p99 改善，也不能把零尺寸绘制计数当作卡顿根因。默认存档恢复保留确认和原件备份；模板日期来自真实清单，解锁进度仍未实机核验。
