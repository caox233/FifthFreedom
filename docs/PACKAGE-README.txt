SCBL LAN 1.1

佣兵新增 SC-IS，间谍新增 VSS；战役原武器不变。
SC-IS 支持滚轮变倍和倍率记忆，射击间隔1.45秒，默认8发装弹/24发备弹。
VSS 默认10/30，长弹匣20/60。新增中文聊天、装备重命名和简体字显示。

吸附式摄影机：保持选中已部署的摄影机，用原部署键单击发一声诱饵枪声，长按持续发声，双击触发原版引爆。单击有约0.25秒双击判定时间；松开停止长按发声。切换道具、菜单或聊天后取消待执行操作。
F9：对局内自杀，冷却10秒，不是10秒倒计时。聊天或重命名时不触发。

关闭旧版后完整解压到新目录，再运行 SCBL.LAN.exe，选择 Blacklist_DX11_game.exe。
所有玩家和服务端使用同一完整包，不要混换DLL。先备份旧 data，不要覆盖自己的存档。
本包不包含游戏本体，仅支持DX11。只在可信局域网或加密组网环境使用，不要直接暴露公网。

正式配置关闭开发用F1～F8诊断，F5接受邀请保留。问题反馈请用启动器“导出诊断包”，不需要按开发诊断键。本地日志和崩溃摘要保留，不自动保存完整转储或上传。
MOD人数上限为8；OB未开放，不含额外观察者位。

摄影机新操作、F9、VSS的ATS表现，以及远端听距、团队中文接收、不同护甲伤害、VSS个别显示、RFD和无人机声音，仍需更多实际对局反馈。
完整更新说明见源码 docs/RELEASE-NOTES.md；程序包附带的更新公告列出相同变更。
