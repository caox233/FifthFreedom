Fifth Freedom 统一开发候选使用说明

请从对应交付条目确认源码版本、完整包校验值与待验收项。以下步骤适用于完整开发候选；组件产物不能代替完整包，构建通过也不表示所有实机问题已修复。

1. 核对交付条目的 ZIP SHA256。关闭旧版，把实际的 *-program.zip 完整解压到新的可写目录；如果下载的是 GitHub artifact 外层 ZIP，先取出其中的 program ZIP。包根应有 FifthFreedom.exe、runtime、package 和 licenses。runtime 中的 FifthFreedom.Server.exe、uplay_r1_loader.dll、scbl_gameplay.dll 及校验文件必须配套保留；package 中的目录与清单不能搬散。所有玩家和服务端使用同一完整候选，不混换 DLL，不覆盖旧 data 或自己的存档。本包不含游戏本体，仅支持 Blacklist_DX11_game.exe（DX11）。

2. 打开 FifthFreedom.exe，选择“LAN · 局域网”和自己的“联机网卡 / IPv4”。每人使用不同账号；账号可用英文、数字、下划线、短横线、点。每轮统一“游戏模式”为 MOD 或官方，并选择相同的游戏内玩法。Public 当前不可用；公网示例中的 .invalid 不是可连接地址，不要填旧部署默认。

3. 只让一台电脑创建房主：先填账号名、选网卡，再点“创建房主”并确认。这会启动本包 runtime/FifthFreedom.Server.exe，不会自动启动游戏。其他玩家选“加入房主”，填写房主实际 IPv4:50051，再点“检测网络”。这是 API 端口；不是 :80，也不是别人电脑的 127.0.0.1。自动发现不可用时可手填。保持房主启动器开启；关闭它或切回加入模式会停止它拥有的服务端。

4. 启动器当前不会自动添加防火墙规则。仅对可信测试网络及测试对端，手动允许实际运行的 runtime/FifthFreedom.Server.exe 入站 TCP 80、8000、50051 和 UDP 21126、21127；另允许 FifthFreedom.exe 的 UDP 47777 入站（发现/玩家列表）。各玩家还需允许实际 Blacklist_DX11_game.exe 与同伴通信。不要关闭整个防火墙或直接暴露公网；端口冲突应先确认并处理实际占用程序。服务器检测通过不代表游戏内 P2P 已互通。

5. 每位玩家填写自己的账号、密码，手动点击“启动游戏”；需要选择程序时选 Blacklist_DX11_game.exe。新账号会提示注册，恢复码请自行保管。正常启动不替换基础存档；联机测试无需点击“恢复存档”或“诊断启动一次”，也无需手写带密码的配置。

快速匹配：至少两个独立客户端、不同账号，同服同官方/MOD模式，使用游戏内“快速匹配”入口。分别检查已有房间与无预建房间时的同局结果：双方应出现在同一成员表并进入同一局，两个各自成功的大厅不算通过。不要用手动邀请代替。Fast/Compatible 是公网传输选项，与此问题不同；原多人现象仍待验证。

聊天中转：使用 MOD，A 为游戏房主、B/C 为加入者。B 发全体消息时 A/C 都应收到；B/C 同队、A 敌队时，团队消息应到 C 而不显示给 A。再换队确认敌方加入者 C 不收到团队消息。房主收到或发送者看见自己发言不能证明第三端收到；不要用 OB 替代玩家。

记录简短的通过/未通过、入房阶段或未收件端即可；本说明不要求新增日志、截图或采集。保留已通过的 F3 变倍、MAC-11 HUD、本机中文输入/世界相机、VSS EMF 结果，不要求逐条重测。历史功能说明见随包“更新公告.txt”，本次通过范围以对应候选的验收记录为准。
