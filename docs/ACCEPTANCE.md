## 状态如何解释

- **用户确认**：用户在当时候选和设备上报告通过；不等于独立复验或全部环境通过。
- **离线通过**：源码、单元、原生指令回放、构建或 GPU 捕获回放通过；不是实机验收。
- **待验收/待定位**：保留到 [剩余待办](tasks/remaining-bugs.md)，不阻塞项目迁移。
- 旧记录可能同时保留早期失败的 `remaining` 与更新后的 `current_scope_accepted`。
  下表使用最新明确反馈；早期失败不是自动重新打开已通过项目的理由。

## 迁移后的使用规则

1. `src/` 的 LAN 行为是保留基线；`integration/scbl3/` 是 UI/公网服务的供体，不是已验收替代品。
2. 先读 [实现与历史索引](DEVELOPMENT-HISTORY.md) 和 [剩余待办](tasks/remaining-bugs.md)。
3. 重构须运行受影响合同、完整构建及包校验；真实图形/声音/联网验收继续由用户集中完成。
4. 不自动启动游戏或采集。没有新失败证据，不要求重测 F3、MAC-11 HUD、中文输入、
   已通过长按射击、世界稳定和已确认 VSS EMF 显示。
5. 迁移完成不等于剩余缺陷完成；不得清空历史记录以使新项目看起来全绿。
